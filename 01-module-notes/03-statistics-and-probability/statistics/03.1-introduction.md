
# What is Statistics?
A science of data (A branch of Mathematics) that involves collecting, analyzing, presenting and interpreting data.

## Importance of Learning Statistics
* To summarize data.
* To conclude data.
* To make reliable forecasts about business activities.
* To improve the business process (quality control).

## Statistical Model
- What is a Statistical Model

Example: 
* If one wants to guess how much a house will cost, one cannot predict it perfectly. But one known that bigger houses generally cost more. A _statistical model is the mathematical line that connects **house size** to **house price**, while accepting that there will be a little bit of guesswork or "error" involved._


A statistical model - is a mathematical representation that describes how a set of data is generated and show the relationship between random and non-random variable.

* A statistical model represents observed data as:
 $$Y = g(\mathbf{x}) + \varepsilon$$

Where:

- $Y$: **Target/Label** - The continuous output variable that one wants the model to predict (e.g., house price, stock value, temperature)

- $x$: **Features/Inputs** - The vector of input variables you feed into the model (square footage, number of rooms, zip code).

- $g(x)$: **The Target Function/Deterministic Function** - The perfect/true, hidden formula nature uses to process those inputs/features to targets with variance $\sigma^2$. 

    * We can see the inputs, and we can see the outcomes, but _we never get to see the actual formula_ $g(x)$. A machine learning model's entire job is to make its best guess at what that hidden formula looks like.
    
- $\hat{g}(\mathbf{x})$ - (g-hat): **The ML Model / Hypothesis** - This is the algorithm one trains (_like a Linear Regression, Random Forest, or Neural Network_) to mimic $g(x)$ as closely as possible.

    * Nature holds the true formula $g$, and the machine learning model is our trained copycat $\hat{g}$ trying to duplicate it.

- $\varepsilon$: **Irreducible Error** - The random noise that one can never clean out, no matter how powerful you machine model is.
