
# Introduction to Machine Learning 

What is Machine Learning?
- A form of artificial intelligence, where machines are taught to do tasks without being explicitly programmed. 

## Characteristics of Machine Learning.  
1. Learns relationship between data

2. It can predict events for other data.

3. Improve performance with respect to experience.

## Applications of Machine Learning 
* Medical diagnosis 

* Stock market trading 

Product recommendations

* Speech recognition

* Self-driving cars 

* Automatic language translation

* Spam email filtering 

* Image recognition

## Real World Application 
* Detect cancer and brain tumors 

* Tesla self-driving cars

* Gmail spam emails filtering

* Google translator 

* Face detection to unlock a device. (Siri, Cortana, Alexa) 

## Machine Learning Methods 

1. Supervised Learning 

2. Unsupervised Learning 

3. Reinforcement Learning
