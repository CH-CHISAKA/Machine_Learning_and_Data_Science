# The Virtual Environment (`.venv`) and the List of Packages File (`requirements.txt`)

## Project Setup Instructions
1. Confirming the python version
    ```shell
        python3 --version
    ```

2. Create the python environment (`.venv`)
    ```shell
        python3 -m venv .venv
    ```

3. Activate the virtual environment 
    ```shell
        source .venv/bin/activate
    ```
4. Creating the `requirements.txt` File
    ```shell
        pip install -r requirements.txt
    ```
5.  Confirming the installed packages using:

   ```shell
        pip list
   ```
